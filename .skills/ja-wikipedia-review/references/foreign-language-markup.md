# 外国語表記と言語タグの査読基準

このファイルは、日本語本文中の外国語の語句、原語併記、外国語名ラベル、Lang系テンプレート、IETF言語タグを査読するときに使う。見た目の統一だけでなく、読者への言語表示と、ブラウザー・スクリーンリーダーへ渡る機械可読な言語情報を分けて確認する。

## 根拠と位置付け

- [Wikipedia:アクセシビリティ § 外国語](https://ja.wikipedia.org/wiki/Wikipedia:アクセシビリティ#外国語)はガイドラインであり、日本語以外の語句に`{{Lang}}`を用いるよう示している。平文の外国語をスクリーンリーダーが誤った言語として発音し得ることが実質的な理由である。
- [Template:Lang/doc](https://ja.wikipedia.org/wiki/Template:Lang/doc)は、IETF言語タグ、言語別フォント、読み上げ、検索・再利用等の技術的用途を説明するテンプレート解説である。
- [Template:Lang-en/doc](https://ja.wikipedia.org/wiki/Template:Lang-en/doc)は、言語名を表示する通常版・略記版、反復時の`links`、言語タグだけを指定するテンプレートとの使い分けを説明する。テンプレート解説だけを方針またはガイドラインと同じ強さで引用しない。
- テンプレート名、引数、展開結果は変わり得る。査読時に現行の解説、TemplateData、実装、表示を確認する。

## 何を候補として抽出するか

全文査読では、表示される本文とウィキテキストの両方から少なくとも次を探す。

- `英: abc`、`英語: abc`、`English: abc`、`en: abc`のように、言語名・略号とコロンを平文で直書きした外国語表記。
- `仏:`、`独語:`、`中国語:`等、他言語について同じ構造を持つ表記。英語だけを検査して完了としない。
- 日本語名の直後に括弧で併記された外国語名、外国語の題名、引用、標語、文、語義を説明するため提示された語。
- `{{Lang...}}`、`{{En...}}`、`{{Rtl-lang...}}`、翻字系・引用系テンプレート、直接の`<span lang="...">`等、すでに言語情報を与えている構文。
- 同じ記事内で、平文ラベル、通常版、略記版、タグのみの方式が混在している箇所。

検索ヒット数をそのまま問題件数にしない。コメント、`nowiki`、構文例、URL、コード、識別子、ファイル名、数式、化学式、型番、テンプレート名、引数名を表示本文の外国語句と誤認しない。

## 平文の言語ラベルを判定する

`英: abc`のような表記では、人間には言語名が見えても、`abc`自体に`lang="en"`が付くとは限らない。次の順で判定する。

1. `abc`が実際に英語なのか、固有名、略語、コード、別言語のラテン文字表記等なのかを文脈と信頼できる資料で確認する。
2. ソースまたは展開元に、対象範囲へ正しい言語タグを付けるテンプレート・HTML属性がすでにないか確認する。
3. 展開後HTMLで対象語句を囲む要素の`lang`値を確認する。画面に`英:`と出ること、CSSクラス名、テンプレート名だけでタグ付与済みと推測しない。
4. タグがない場合、言語名を読者にも表示する必要があるか、機械可読なタグだけでよいかを決める。
5. 同じ言語表記が反復する場合、言語記事への反復リンクとラベルの冗長さを別に評価する。

言語名を平文で書いた後、外国語部分だけを正しく`{{Lang|en|abc}}`等で囲んでいる場合、言語タグ欠落としては指摘しない。見た目や保守性のためLang-en系へ統一するかは、記事内の方式と分野別合意を確認し、好みだけで要求しない。

## 表示目的に応じた構文の選択

| 必要な表示・役割 | 英語の場合の代表例 | 査読上の注意 |
| --- | --- | --- |
| 短い言語ラベルと外国語表記を一体で表示 | `{{Lang-en-short|abc}}` | `英: abc`相当。現行の解説と実際の展開でラベル、リンク、`lang`属性を確認する |
| 完全な言語名と外国語表記を表示 | `{{Lang-en|abc}}` | `英語: abc`相当。初出や言語名の明示が有用な文脈で検討する |
| 見える言語ラベルを増やさず言語だけ指定 | `{{Lang|en|abc}}`または現行の言語別タグ用テンプレート | 前後の文章だけで言語が明らか、またはラベルが不要な場合 |
| 地域・時代・用字系まで区別 | 対応する言語別テンプレート、または妥当なBCP 47タグ | `en`、`en-GB`、`en-US`等を内容以上に細分化しない |
| 右横書き、翻字、引用テンプレート内 | 各専用テンプレートの言語引数 | `dir`、翻字元、表示・読み上げを展開後に確認する |

`{{Lang-en-short}}`は、平文の`英:`を見つけたときの有力な修正候補だが、常に唯一の正解ではない。言語名を完全形で示す必要があれば通常版、ラベルが不要ならタグのみの方式を選ぶ。単にソースを短くする目的でshort版を選ばない。

同じ言語名リンクを繰り返す必要がない場合、現行解説で対応していれば`|links=no`を検討する。ただし、言語タグまで消える方式や、外国語部分を平文化する修正へ置き換えない。

## 言語タグと範囲

- IETF/BCP 47に沿う有効なタグか確認し、対象語句の実際の言語・用字系・地域と一致させる。`en`で十分な英語を根拠なく`en-US`等へ限定しない。
- タグの範囲は外国語部分だけにする。周囲の日本語、読点、訳語、脚注番号まで外国語として囲まない。
- 一つの範囲に複数言語が混在する場合、最外側へ一つのタグを付けて済ませず、意味のある最小範囲へ分ける。
- ラベルと内容が食い違うもの、たとえば表示が「英語」なのに`lang="fr"`となるものは、単なる書式不統一ではなく誤った言語指定として報告する。
- 内部リンク、斜体、引用符を含む場合、Lang系テンプレートの引数境界、リンク範囲、展開HTMLが壊れていないか確認する。装飾のために言語タグを外さない。
- すでに正しい`lang`属性を出すテンプレートや直接HTMLがある箇所へ、Lang系テンプレートを二重に重ねない。

## 適用除外と誤修正防止

- CS1/CS2、和書用出典表記等の出典テンプレートの引数内にLang系テンプレートを埋め込まない。マークアップがCOinSメタデータを壊し得るため、そのテンプレートが用意する`language`等の引数、平文の書誌値、または現行解説が指定する方法を使う。
- URL、メールアドレス、プログラムコード、コマンド、識別子、型番、数式、化学式へ、通常の外国語文章と同じ方法でLang系テンプレートを機械適用しない。
- 日本語資料でもそのまま固有名・製品名・略語として使われる短いラテン文字列を、文字種だけで外国語の語句と断定しない。ただし`英:`等のラベルで言語が明示されている場合は、タグ欠落を確認する強い手掛かりになる。
- テンプレート、インフォボックス、引用、外部リンクラベル等が言語属性を生成する場合、呼び出し側のソースに`{{Lang}}`がないことだけで欠落としない。
- 言語が判定できない語句へ推測でタグを付けない。原語、翻字、言語不明を区別し、不明なら`要確認`とする。
- 外国語併記自体が冗長、無出典、または本文理解に不要な場合、Lang化して温存する前に、併記の必要性を評価する。

## 記事全体の一貫性と報告

全文査読では、少なくとも次を記録する。

| 項目 | 内容 |
| --- | --- |
| 平文候補 | `英:`等の種類、出現数、節、代表例 |
| 言語情報 | タグなし、正しいタグ、誤ったタグ、範囲不正、展開未確認 |
| 表示方式 | 通常ラベル、短縮ラベル、タグのみ、専用テンプレート、直接HTML |
| 例外 | COinS、コード、URL、識別子、既存テンプレート生成等 |
| 推奨 | Lang-en-short等へ置換、通常版、タグのみ、既存構文維持、併記削除、要確認 |

同じ原因による平文表記は一件にまとめ、総数と代表例を示す。局所的なタグ欠落や表示方式の混在は通常`軽微`とする。長い外国語文、右横書き、記事全体に及ぶ欠落、誤った言語指定により読み上げ・表示・意味の誤認へ実害がある場合は`中`も検討する。テンプレート解説にある一方式を採用していないことだけを「方針違反」と断定せず、ガイドライン上の外国語タグ要請と具体的なアクセシビリティ上の影響を根拠に説明する。
