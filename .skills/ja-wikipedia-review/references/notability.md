# 独立記事作成の目安の査読基準

このファイルは、記事全体、立項前点検、削除・統合・リダイレクトの検討、または特筆性の評価で使う。日本語版の現行ガイドライン上の名称は「独立記事作成の目安」であり、「特筆性」は旧称として残る表現である。

## 根拠文書の優先順位

1. `Wikipedia:独立記事作成の目安`の一般的な目安を基準にする。
2. 主題別の正式なガイドラインがあれば併用する。
3. 関連ウィキプロジェクトまたは記事ノートに成立した合意があれば、適用対象と範囲を確認して併用する。
4. 草案、提案中、私論は具体的な探索・検討観点として使えるが、それ単独で合否を断定しない。

2026年8月28日の調査では、`Wikipedia:特筆性 (人物)`と`Wikipedia:特筆性 (組織)`はいずれも `Proposed` 表示の草案である。ページ本文が自らを「ガイドライン」と呼んでいても、冒頭の状態表示と一般ガイドライン側の一覧を優先して状態を判定する。査読時には必ずライブ版を確認する。

英語版その他の言語版の特筆性基準は、日本語版の規則として適用しない。日本語版に対応文書がない場合、比較資料であることを明示し、合否の根拠にしない。

## 一般的な目安

主題が、主題と無関係な信頼できる二次情報源で有意に言及されていれば、独立記事として扱う価値があると推定できる。次の要件を分解して評価する。

### 主題から独立している

- 主題本人、役員、従業員、所属組織、親会社、子会社、代理店、広報会社、販売者、スポンサー、提携先などから編集上独立しているか。
- 公式サイト、公式SNS、自伝、社史、プレスリリース、広告、販売ページ、会社紹介、採用情報、プロモーション動画は、通常、独立性を立証しない。
- プレスリリースをニュースサイトがほぼそのまま転載した記事は、掲載媒体が別でも独立した報道とは数えない。
- 主題との利害関係が開示されていない寄稿、提供記事、タイアップ、アフィリエイト記事にも注意する。

### 信頼できる

- 当該分野について、著者性、専門性、編集上の監督、訂正方針、媒体の評判が十分か。
- 全国紙である、学術誌である、官公庁であるという名称だけで、すべての用途に適格としない。
- 利用者投稿、無署名ブログ、まとめサイト、検索スニペット、生成AIの回答は、目安を立証する情報源として扱わない。
- 有料・紙媒体・データベース収録資料は、オンラインで無料閲覧できないことだけで不適格にしない。

### 二次情報源である

- 主題について第三者が選択、分析、評価、文脈付けを行った資料か。
- 登記、決算、統計、裁判記録、議会記録、作品そのもの、公式プロフィールなどの一次資料は、率直な事実の検証には使えても、主題が独立記事に値することを通常は立証しない。
- データベースや名簿が編集された資料でも、項目が定型的な基本情報だけなら、有意な言及とは別に評価する。

### 有意な言及である

- 主題を直接扱い、読者が主題についてまとまった理解を得られる深さがあるか。
- 一文だけの言及、名簿、受賞者一覧、製品一覧、出演者一覧、試合結果、株価表、所在地や営業時間などの定型情報は、通常、それだけでは有意な言及にならない。
- 主題を中心にした記事、章、評伝、批評、調査報道、ドキュメンタリーなどは強い根拠になり得る。
- 一つの長く包括的な資料だけで立証する場合、その資料の独立性、信頼性、中立性、検証可能性、対象への詳細さを特に厳しく確認する。通常は複数の独立資料が望ましい。

### 推定であって保証ではない

- 一般的な目安を満たしても、名鑑、広告、ニュース速報、データベースなど「ウィキペディアは何ではないか」に反する記事形態は適切でない場合がある。
- 目安を満たさない要素を多数足しても、自動的に有意な言及になるわけではない。一方、各資料が基準にわずかに届かない場合は、合算して得られる情報の深さを具体的に検討する。
- 記事の長さ、文章品質、脚注数、ページビュー、検索件数、SNSフォロワー数は、目安そのものではない。

## 情報源調査の手順

### 1. 主題の境界を固定する

- 正式名称、旧称、通称、改名前の名称、原語表記、別綴りを記録する。
- 人物とその作品、企業と製品、親組織と支部、グループと各メンバーなど、何について独立記事作成の目安を判断するかを分ける。
- 同名異人・同名組織の記事を混同しない。所在地、活動期間、役職、業種などで同定する。

### 2. 記事内の候補資料を棚卸しする

各出典を次の表に整理する。

| 項目 | 記録内容 |
| --- | --- |
| 資料 | 著者、題名、媒体、日付、URLまたは書誌情報 |
| 独立性 | 独立 / 関係あり / 不明。具体的な関係 |
| 信頼性 | 高い / 用途限定 / 弱い / 未確認。理由 |
| 資料種別 | 二次 / 一次 / 三次 / 判定不能 |
| 言及の深さ | 主題中心 / 複数段落 / 一節 / 一文 / 名簿・定型情報 |
| 情報の系統 | 独自取材・分析 / 他社転載 / 通信社配信 / プレスリリース由来 / 不明 |
| 一般基準への寄与 | 強い / 補助的 / 寄与しない / 内容未確認 |

脚注数ではなく、独立した情報系統の数を数える。同じ通信社記事の転載、同じプレスリリースの書き換え、同一出版社による再版は、複数の独立資料とみなさない。

### 3. 記事外を誠実に探索する

- 正式名称だけでなく、旧称、原語、略称、人物名と職業、組織名と所在地・業種などを組み合わせる。
- 一般検索だけでなく、ニュースアーカイブ、書籍、学術文献、図書館目録、業界誌、地域紙、公的資料を主題に応じて調べる。
- 歴史的主題では現在のウェブ検索だけに頼らず、当時の新聞、雑誌、書籍、縮刷版、データベースを検討する。
- スニペットだけで言及の深さや支持内容を確定しない。可能なら本文を開き、アクセス不能なら `内容未確認` とする。
- 検索語、対象期間、確認したデータベース、確認できなかった資料を記録する。

削除・統合を勧める前には、少なくとも一般検索以外の妥当な探索先を主題に応じて一つ以上検討する。専門的・歴史的主題では、オンライン検索だけで「情報源が存在しない」と断定しない。

### 4. 判定を合成する

次の表現を使い分ける。

- `立証済み`: 一般基準または正式な分野別基準を満たす根拠を、内容まで確認できた。
- `立証可能性が高い`: 有力な資料はあるが、全文、独立性、言及の深さなど一部の確認が残る。
- `記事内では未立証`: 記事の出典だけでは立証できないが、記事外調査を十分に行っていない。
- `調査範囲では未立証`: 調査範囲を明示した上で、適格な資料を確認できなかった。目安不適合の断定ではない。
- `目安に合致しない可能性が高い`: 誠実な調査を行い、候補資料が独立性・二次資料性・有意性を満たさない理由を示せる。
- `判定不能`: 同定不能、主要資料へアクセス不能、文書状態や分野別合意が不明など、結論を妨げる制約がある。

`特筆性あり / なし` の二値だけで報告しない。根拠資料と未確認事項を併記する。

## 時間、報道量、継承に関する誤判定

- 一度、適格な資料によって目安に合致したことが立証されれば、現在の知名度低下だけで失われない。
- 現時点で資料が不足している主題を、将来有名になるという予測だけで立項可能としない。後に資料が揃えば再評価できる。
- 単発の出来事、試合結果、ゴシップ、製品発表、決算、開店・閉店、役員就任などの定常的報道は、量が多くても批評的分析や持続的影響がなければ有意な言及とは限らない。
- 短期間に同一発表を多数媒体が伝えた状態を、長期的・独立した注目と混同しない。
- 人物は親族、所属組織、作品、受賞イベントから目安を自動的に継承しない。組織も親会社、著名な創業者、製品、支部から継承しない。各主題への直接的な言及を探す。

## 人物の評価

`Wikipedia:特筆性 (人物)`は草案である。以下は探索と論点整理に使い、一般基準または正式なプロジェクト合意なしに機械的な合格条件としない。

### 共通事項

- 本人から独立した信頼できる二次資料で、人物自身がまとまって扱われているか。
- 一次資料は経歴の検証には使えても、人物が独立記事に値することを通常は立証しない。
- 有名人の親族、著名作品への参加、著名組織への所属だけでは目安を継承しない。
- 検索件数、写真数、SNSフォロワー数、プロフィールデータベースへの掲載を根拠にしない。
- よく知られた賞、歴史に残る貢献、人物を主題とする評伝・批評などは有力な検討材料だが、賞の権威や資料の独立性を確認する。

### 一つの出来事で知られる人物

- 報道の中心が人物ではなく事件・事故・選挙・番組など一つの出来事なら、出来事の記事内で扱う方が適切か検討する。
- 情報源が人物の生涯、活動、影響を出来事とは独立して詳しく扱う場合や、出来事記事では収まらない継続的報道がある場合は、人物記事の根拠になり得る。
- 存命人物、とくに犯罪被疑者、被害者、私人では、目安と別にプライバシー、実名記載、否定的記述の厳格な出典要件を確認する。

### 職業・役割別の確認先

- 政治家: 公職名だけでなく、その地位の範囲、当選か立候補のみか、政治活動への独立した報道を確認する。地方議員や候補者は肩書だけで判断しない。
- 外交官・司法官: 役職の水準だけでなく、重要な出来事への関与と独立した言及を確認する。
- スポーツ選手: 世界記録、代表選出、最高水準の大会・リーグでの実績に加え、競技別ウィキプロジェクトの現行基準と資料による立証を確認する。
- 芸能人・音楽家: 重要な役割、主要な賞、分野への独自または持続的貢献、人物自身への報道を確認する。音楽分野では正式な `Wikipedia:特筆性 (音楽)`もライブ確認する。
- 創作者: 作品が独立した批評・研究・特集の対象になっているか、重要な概念・作品への寄与が第三者資料で評価されているかを確認する。
- 学者・研究者: 権威ある賞、分野内での評価、影響力のある著作・概念、独立したレビューや研究上の言及を確認する。所属、職位、論文数だけで判断しない。
- その他の職業: 草案に項目がないことを不適合の根拠にせず、一般基準へ戻る。

具体的な大会、賞、役職の列挙は改訂され得る。査読時には人物草案と関連プロジェクトの最新版・状態表示・ノートでの合意を確認する。

## 組織、企業、製品、サービスの評価

`Wikipedia:特筆性 (組織)`は草案である。企業、非営利団体、教育機関、研究所、利益団体、宗教団体、個人事業、製品、サービスなどの探索観点として使う。

### 共通事項

- 組織から独立した二次資料で、組織そのものが実質的に扱われているか。
- プレスリリース、会社案内、社史、公式ブログ、採用記事、広告記事、提供記事、プロモーション動画、その転載を除外しても根拠が残るか。
- 所在地、営業時間、設立、資本金、売上、従業員数、上場、資金調達、製品発売、受賞などの定型的事実だけでなく、組織の活動、影響、評価を扱う独立資料があるか。
- 規模、存続年数、構成員数、全国展開、国際展開は検討材料になり得るが、それだけを決定的基準にしない。
- 企業データベース、登記、証券取引所資料、決算資料は事実確認には使えても、通常、それだけでは有意な言及を立証しない。

### 報道の質と系統

- 創業、資金調達、製品発表、提携、決算、上場、買収、閉鎖に関する短いニュースが、プレスリリース由来の定常報道ではないか確認する。
- 業界誌・地域紙は、それだけで弱いとは限らない。主題との利害関係、編集体制、記事の深さ、独自取材の有無を評価する。
- 同じ発表を複数媒体が転載していても一系統として数える。独自の取材、批評、比較、歴史的文脈がある資料を優先する。
- 製品レビューは、編集上独立し、十分に詳細で、広告・アフィリエイト関係を評価できる場合に限り、製品の根拠になり得る。会社全体への目安を自動的に立証しない。

### 親組織、支部、店舗、子会社

- 親組織が目安を満たしても、支部、地域組織、子会社、個別店舗へ自動的に継承しない。
- 全国・国際規模の組織でも、個々の支部はその支部への独立した有意な言及がなければ、親組織の記事や一覧で扱うことを検討する。
- 地域限定の組織だから不適合と決めつけず、地域史、地域紙、専門書などに十分な独立資料があるかを調べる。
- チェーンやフランチャイズの個別店舗は通常、親記事で扱う。建築、歴史、事件など店舗自体への有意な言及があっても、店舗記事ではなく建築物・出来事の記事が適切かを比較する。

### 製品とサービス

- 会社が目安を満たしても個別製品・サービスは自動的に満たさず、その逆も同様である。
- 独立した批評、比較、技術史・文化史上の分析、継続的な報道がある製品・サービスは独立記事の候補になり得る。
- 製品仕様、価格、発売日、更新履歴、販売ページ、公式マニュアルだけなら、会社記事内の要約または製品一覧が適切か検討する。
- 独立記事として十分な資料がなければ、親会社、製品群、技術分野など、読者に文脈を与えるより広い記事への統合・リダイレクトを検討する。

### 非営利組織

- 全国・国際規模、活動年数、会員数、支部数は補助材料であり、独立資料による実質的な報道を確認する。
- 組織自身の活動報告、寄付募集、助成申請、関係者の推薦文だけで社会的影響を立証しない。
- 地域組織でも、歴史的役割、政策・社会への影響、論争、独立した研究などが詳しく扱われていれば一般基準を満たし得る。

## 主題別文書とプロジェクト合意

一般基準の関連項目から、対象分野の現行文書を探す。2026年8月28日の一般ガイドラインでは、音楽はガイドライン、人物・組織・ウェブ・災害・事件・書籍などの多くは草案、フィクションは私論として列挙されている。

スポーツ選手、サッカークラブ、医療機関、郵便局、行政機関、大学関係組織、映画、鉄道、地名などでは、ウィキプロジェクトに記事作成基準がある場合がある。次を確認する。

- その文書が方針、ガイドライン、草案、私論、プロジェクト合意のどれか。
- 合意が現在も有効か、告知や改訂提案がないか。
- 対象の国、時代、競技、組織種別に適用されるか。
- 主題別基準を満たすことが、一般基準を代替するのか、補助するのか。

基準に数値や肩書がある場合も、出典による事実の立証は別に必要である。

## 改善・統合・削除の提案

- まず適格な情報源を記事へ追加し、目安を記事中で立証できるか検討する。
- 独立記事に足る資料は弱いが検証可能な情報がある場合、より広い記事への統合またはリダイレクトを検討する。
- 一つの出来事で知られる人物は出来事記事、支部は親組織、製品は会社または製品群の記事など、主題の境界を組み替える。
- 削除は誠実な情報源調査と代替案の検討後の選択肢とする。査読依頼だけではテンプレート貼付、統合、リダイレクト、削除依頼などを実行しない。
- 法的・存命人物上の危険、明白な宣伝、著作権侵害は、目安の評価とは別に緊急度を判断する。

## 出力要件

特筆性評価を行った場合、次を必ず示す。

1. `主題の境界`: 誰・どの組織・どの製品を評価したか。
2. `適用基準`: 一般基準と主題別文書、その文書状態。
3. `情報源評価`: 候補資料ごとの独立性、信頼性、二次資料性、言及の深さ、系統。
4. `調査範囲`: 検索語、媒体・データベース、期間、アクセスできなかった資料。
5. `判定`: `立証済み`、`立証可能性が高い`、`記事内では未立証`、`調査範囲では未立証`、`目安に合致しない可能性が高い`、`判定不能`のいずれか。
6. `理由`: どの要件をどの資料が満たすか、または満たさないか。
7. `次の対応`: 出典追加、追加調査、統合、リダイレクト、削除検討など。外部変更は実行しない。

根拠ページと調査固定版は [sources.md](sources.md) を参照する。
