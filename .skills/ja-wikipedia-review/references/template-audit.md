# テンプレートと引数の査読基準

このファイルは、記事全体またはテンプレートを含むウィキテキストを査読するときに使う。テンプレート名の有無だけでなく、直接入力、引数、展開結果、間接依存、エラーの発生元を分けて確認する。

## 根拠の扱い

- 日本語版の現行テンプレート解説と、そのテンプレートを管理するウィキプロジェクトまたはノートでの合意を優先する。
- [Help:テンプレート](https://ja.wikipedia.org/wiki/Help:テンプレート)は呼び出し、引数、重複、`=`、展開の技術仕様に使う。
- [TemplateData](https://www.mediawiki.org/wiki/Extension:TemplateData)は引数名、別名、型、必須、推奨、非推奨などを機械可読にする編集支援情報である。TemplateDataが実際のテンプレート実装と一致するとは限らず、`required`も保存や展開を必ず拒否する機能ではない。
- テンプレートが [モジュール:Check for unknown parameters](https://ja.wikipedia.org/wiki/モジュール:Check_for_unknown_parameters) などを利用している場合、その出力と追跡カテゴリも確認する。すべてのテンプレートが未知の引数を検出するとは限らない。

## 直接呼び出しと展開依存を分ける

1. 対象版のウィキテキストから、直接記述された `{{...}}`を列挙する。コメント、`nowiki`、例示コード中の文字列を呼び出しと誤認しない。
2. MediaWiki APIの`action=parse`の`templates`、または`prop=templates`で、展開中に参照されるテンプレート、モジュール、スタイルを確認する。
3. 直接呼び出し、テンプレート経由、Luaモジュール、TemplateStyles、Wikidata依存を区別する。
4. 表示、ページプロパティ、通常カテゴリ、隠しカテゴリ、追跡カテゴリを照合する。ソース検索件数と展開後件数が異なること自体はエラーではない。

対象版の固定が必要である。テンプレート側の不具合を論じる場合は、記事の版に加え、確認したテンプレート、解説、モジュールの版または確認日時も記録する。

## テンプレートごとの判定

記事に直接ある各テンプレートについて次を確認する。

- `目的`: 記事内で必要な役割があり、同じ情報や機能を重複していないか。
- `現行性`: テンプレート名がリダイレクト、旧名、廃止、統合予定になっていないか。リダイレクトだから直ちに置換が必要とは限らない。
- `適用範囲`: 記事名前空間、主題、分野別プロジェクト、人物・組織・地理などの対象条件を満たすか。
- `引数`: 名前付きと名無しの区別、番号、綴り、大文字小文字、別名、値の型、許容値、単位、日付形式、空欄の意味を確認する。
- `関係`: 必須・推奨・非推奨、排他的な引数、同時指定が必要な引数、番号付き引数群の欠番や対応ずれを確認する。
- `重複`: 同じ名前の引数、同じ番号の名無し引数、引数とその別名の同時指定を探す。MediaWikiでは同名引数の後方が有効になる場合があり、見た目が正しくても前方の値が捨てられていないか確認する。
- `構文`: 値中の半角`=`、パイプ、閉じ括弧、改行、HTML、脚注、入れ子テンプレートが引数境界を壊していないか確認する。名無し引数に`=`が入る場合は番号指定などが必要になる。
- `出力`: 未展開の`{{{引数}}}`、赤いエラー、空出力、不自然なカテゴリ、リンク先、数値、日付、画像、地図を確認する。
- `アクセシビリティ`: 表示を色、アイコン、画像、折り畳みだけに依存していないか。固定幅や長大なナビゲーションが本文を損なっていないか。

## TemplateDataと解説の照合

TemplateDataがある場合は、現行のAPIから取得する。

```text
https://ja.wikipedia.org/w/api.php?action=templatedata&titles=Template:テンプレート名&redirects=1&format=json&formatversion=2
```

次を照合する。

- 呼び出し側の引数名が`params`または`aliases`にあるか。
- `required`が欠けていないか。ただし、空欄を実装が許すかも解説と表示で確認する。
- `deprecated`の引数を新しい引数へ移行できるか。
- `type`、`suggestedvalues`、`default`と実際の値が矛盾しないか。
- 解説の全引数一覧、使用例、TemplateData、テンプレートまたはLua実装が食い違っていないか。

TemplateDataがない、古い、または可変長の名無し引数を十分表現できない場合は、欠落自体を記事の問題にしない。現行解説、テンプレートソース、モジュール、表示、追跡カテゴリを使って確認し、検証できない引数は`未確認`とする。

## エラーと追跡カテゴリ

- `Category:テンプレート呼び出しで引数が重複しているページ`など、記事の実効カテゴリを確認する。
- CS1、典拠管理、座標、Infobox、未知の引数など、各テンプレート固有の追跡カテゴリとプレビュー警告を確認する。
- エラー文が表示されなくても、空出力、隠しカテゴリ、ページ情報、APIに問題が現れる場合がある。
- 追跡カテゴリは即座に方針違反を意味しない。エラー、保守対象、意図的な抑制、情報不足を区別する。

## 発生元の切り分け

次の順で原因を特定する。

1. 記事側のテンプレート名または引数が誤っている。
2. 記事が参照するWikidata、Commonsデータ、その他の外部データが誤っている。
3. 共有テンプレート、Luaモジュール、TemplateStylesに問題がある。
4. キャッシュまたはジョブキューによる反映待ちである。

記事側の入力が正しい場合、共有テンプレートの問題を記事から回避する変更は原則として勧めない。発生元、影響する表示、確認版を示し、修正先を分けて報告する。

## 報告

全文査読では、主要な直接テンプレートについて少なくとも次を記録する。

| 項目 | 内容 |
| --- | --- |
| テンプレート | 現行名、直接・間接、目的 |
| 入力 | 引数、別名、必須・非推奨、重複 |
| 展開 | 表示、モジュール、スタイル、Wikidata等の依存 |
| 実効状態 | エラー、追跡カテゴリ、ページプロパティ |
| 判定 | 問題なし / 記事側 / 共有側 / 外部データ側 / 未確認 |

誤った引数により重要情報が欠落または誤表示される場合は`中`以上を検討する。未知・重複・非推奨引数でも表示に影響しないものは通常`軽微`だが、捨てられた値や誤った主張がある場合は影響に応じて引き上げる。
