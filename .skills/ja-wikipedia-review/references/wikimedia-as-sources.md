# Wikipedia・姉妹プロジェクト・転載サイトの出典監査

日本語版・他言語版Wikipedia、Wiktionary、Wikidata、Commons等が、本文の事実を支える出典として使われていないかを監査する。ウィキメディア系ページへのリンクを一律に除去せず、`本文の根拠`、`翻訳・転載の履歴表示`、`読者向け案内`、`原資料の閲覧先`、`プロジェクト自身についての一次資料`を区別する。

## 根拠文書

- [Wikipedia:信頼できる情報源 § 情報源](https://ja.wikipedia.org/wiki/Wikipedia:信頼できる情報源#情報源)は、Wikipedia自身の記事を他言語版を含めて出典として引用できないと明記している。
- [Wikipedia:信頼できる情報源 § 掲示板、Wikiで構築されたサイト、Usenetへの投稿](https://ja.wikipedia.org/wiki/Wikipedia:信頼できる情報源#掲示板、Wikiで構築されたサイト、Usenetへの投稿)は、第三者による事実確認や安定性を欠く共同編集Wikiを、原則として一次・二次資料に用いないとしている。同ページの自主公表された情報源に関する限定的例外も合わせて確認する。
- [Wikipedia:翻訳のガイドライン § 翻訳記事で翻訳元記事を出典扱いしない](https://ja.wikipedia.org/wiki/Wikipedia:翻訳のガイドライン#翻訳記事で翻訳元記事を出典扱いしない)は、翻訳元記事の履歴継承と、本文の出典を分けている。
- [Wikipedia:検証可能性](https://ja.wikipedia.org/wiki/Wikipedia:検証可能性)、[Wikipedia:出典を明記する](https://ja.wikipedia.org/wiki/Wikipedia:出典を明記する)、[Wikipedia:独自研究は載せない](https://ja.wikipedia.org/wiki/Wikipedia:独自研究は載せない)も、個々の主張との対応、信頼性、一次資料の扱いを判断する根拠にする。

査読時には現行版の状態表示と該当節を確認する。ここでいう「出典として不適合」は、そのページに書かれた内容が必ず誤りだという意味ではなく、読者が主張を検証するための根拠として適切でないという意味である。

## まずリンクの役割を分類する

対象URL、テンプレート、書誌項目を、次のどれに当たるか分類してから評価する。

1. `本文の根拠`: 記事中の事実、評価、定義、語源、数値等を支える脚注・参考文献。
2. `翻訳・転載の帰属`: 要約欄、ノート、翻訳告知等で翻訳元と版を示すライセンス上の履歴情報。
3. `案内リンク`: Wiktionary、Commons、Wikisource等へ読者を案内する姉妹プロジェクトリンク。
4. `原資料の閲覧先`: 書籍、法令、公文書、画像等の複製や翻刻へアクセスするためのリンク。
5. `プロジェクト自身についての一次資料`: Wikipedia、Wikimedia Foundation、MediaWiki等が自らの規則、仕様、発表、見解を示すページ。

同じURLでも役割により評価が異なる。脚注内にあるから本文の根拠、外部リンク節にあるから案内、と位置だけで決めず、前後の記述と引用方法を確認する。

## サービス別の判定

| 対象 | 本文の事実を支える通常の出典 | 許容され得る別用途 |
| --- | --- | --- |
| 日本語版Wikipediaの記事 | 不適合。内部リンクも出典ではない | 読者向け内部リンク。Wikipedia上の記述自体を論じる場合の限定的な一次資料 |
| 他言語版Wikipediaの記事 | 不適合。翻訳元でも出典にはならない | 言語間リンク、仮リンク、翻訳元の版指定と履歴継承 |
| Wiktionary | 語義、語源、発音、用例等の根拠として原則不適合 | 読者向けの語義案内。専門辞書や言語学資料を別途出典にする |
| Wikiquote、Wikibooks、Wikiversity、Wikivoyage、Wikinews、Meta-Wiki等の共同編集ページ | 原則不適合。編集主体、事実確認、固定性を個別に検査する | プロジェクト自身の活動や掲載状態を述べる限定的な一次資料、姉妹プロジェクト案内 |
| Wikidata | ラベル、説明、主張値、サイトリンク、参照欄を本文の出典にしない | 識別、言語間リンク、テンプレート表示用データ。参照欄が示す原資料は別途確認可能 |
| Commonsの説明文、カテゴリ、Structured Data | 原則不適合 | ファイルの探索、表示、ライセンス・来歴調査の手掛かり |
| Commons上の画像、音声、文書スキャン | それ自体は一次資料になり得るが、解釈・評価の二次資料ではない | 原資料の閲覧先。作者、作成時点、所蔵、出所、改変有無を確認する |
| Wikisourceの本文・翻刻 | 二次資料の代用にしない。転記の正確性と版を自動的に保証しない | 原著作・版を正式に書誌記述したうえでの閲覧先、または適切な範囲の一次資料 |
| Wikimedia Foundationや当該プロジェクトの公式発表 | 独立した二次資料ではない | 発表主体自身の活動、仕様、見解を、帰属を明示して狭く記述する一次・自主公表資料 |
| MediaWiki.org等の技術文書 | 一律に排除せず、文書状態、保守主体、仕様との一致を確認する | MediaWiki機能の公式・準公式な一次技術資料。第三者評価や社会的影響の根拠にはしない |

`wikipedia.org`や`wikimedia.org`というドメイン名だけで機械的に不適合としない。対象プロジェクト、名前空間、ページの編集主体、用途、主張との関係を確認する。一方、Wikipedia記事への固定リンクや永久リンクであっても、版が固定されるだけで情報源としての適格性が生じるわけではない。

## Wikipedia記事と翻訳記事

- 日本語版の記事を別の日本語版記事の根拠として脚注に置く自己引用を検出する。記事への内部リンクは読者案内であり、事実の検証可能性を満たさない。
- 他言語版の記事を翻訳元として要約欄等に版指定することと、その記事を本文の出典にすることを分ける。前者は履歴継承、後者は出典不適合である。
- 翻訳元に脚注があっても無批判に移植しない。各原資料を開き、著者、題名、日付、該当箇所、本文の主張との対応を日本語版側で再確認する。
- 翻訳元Wikipediaの記事だけにある無出典記述は、翻訳したことで検証可能にならない。信頼できる資料を探すか、主張を除去・縮小する。
- Wikipedia記事の参考文献一覧は調査の出発点にはできるが、一覧に載っていること自体を品質保証とみなさない。

## Wiktionaryと語に関する主張

- `英語では…を意味する`、語源、初出、発音、品詞、専門用語の定義等をWiktionaryだけで支えていないか確認する。
- 語義・語源には、専門家・編集部が関与する辞書、語源辞典、言語学文献、用語標準等を探す。Wiktionaryが挙げる参考文献を利用する場合も、その資料を直接確認する。
- `{{Wiktionary}}`等による姉妹プロジェクト案内は、それ自体が本文の出典を装っていなければ咎めない。リンク先の語が記事の主題と一致するか、曖昧な別語へ飛ばないかは確認する。

## CommonsとWikisource

- Commonsのファイル説明やカテゴリに書かれた人物、場所、年代、作者等を、そのまま百科事典本文の根拠にしない。元の所蔵機関、目録、公刊資料等を確認する。
- 画像を見て人物同定、場所同定、年代推定、因果関係等を独自に導かない。画像が直接示す範囲と、二次資料による解釈を分ける。
- WikisourceまたはCommonsが書籍・公文書のスキャンを提供している場合、脚注の書誌情報は原著者、書名、版、発行者、年、ページ等を中心にし、Wikimedia URLは閲覧先として付記する。
- 原資料を使えることと、その原資料から査読者が新しい結論を導けることを混同しない。分析・重要性・因果には信頼できる二次資料を優先する。

## プロジェクト自身について書く場合の限定的使用

Wikipedia、Wiktionary、Wikimedia Foundation、MediaWiki等そのものを主題とする記事では、まず [sourcing.md](sourcing.md) の自主公表・一次資料の基準を適用する。そのうえで、当該主体が自ら公表した規則、仕様、発表、見解等を狭く記述する用途か、必要な帰属があるか、内容が変わり得るページでは確認日と固定版が示されているかを確認する。第三者評価、影響、重要性や論争の真偽には独立した二次資料を求める。

査読でWikipediaの方針・ガイドラインを根拠として示すことは、百科事典本文の主題に関する出典利用とは別である。方針ページは編集判断の根拠として使い、本文中の一般的事実を証明する脚注へ転用しない。

## 転載・循環参照を検出する

Wikipedia以外のドメインでも、Wikipediaの転載、翻訳転載、要約、機械生成による再掲であれば独立した情報源として数えない。次の兆候を調べる。

- 文、段落、見出し、誤記、脚注番号がWikipediaの特定版と不自然なほど一致する。
- フッター、利用規約、奥付、ページソースにWikipedia、CC BY-SA、GFDL、Wikimedia、版ID、転載元への帰属がある。
- ページの公開日がWikipedia側の記述追加後で、独自の著者、取材、編集過程、参考文献が確認できない。
- 出典らしきページがWikipediaへ戻るだけ、または別の転載サイトを経て最終的にWikipediaへ戻る。
- 日本語版が他言語版を翻訳し、外部サイトがそのどちらかを転載した結果、複数資料に見えている。
- 検索結果やAI生成ページがWikipedia文を再構成しているだけで、検証可能な原資料を示さない。

語句の一致だけで転載と断定しない。公開時点、履歴、帰属表示、独自取材の有無、共通する原資料の可能性を照合し、確証がなければ`循環参照の疑い・要確認`とする。信頼できる媒体がWikipediaも参照しつつ独自取材を行っている場合は、記事全体を自動的に排除せず、問題の主張がどの情報に基づくかを確認する。

## 実査手順

1. `<ref>`、名前付き脚注、Harvard方式、参考文献、インフォボックス、表、画像説明、外部リンク節から、URL、DOI、ISBN、題名、発行主体を抽出する。
2. URLについて、ホスト名だけでなく最終転送先、プロジェクト、言語版、名前空間、ページ種別を確認する。短縮URLやアーカイブURLは元URLも復元する。
3. `wikipedia.org`、`wiktionary.org`、`wikidata.org`、`wikimedia.org`、`mediawiki.org`等、および姉妹プロジェクト用テンプレートを抽出し、上記の役割へ分類する。
4. Wikipedia以外の出典も、特徴的な文の検索、帰属表示、公開日、Wikipediaの履歴を用いて転載・循環参照でないか確認する。全出典を無差別に全文照合するのではなく、文章一致や出所不明などの兆候がある資料を重点確認する。
5. Wikipediaまたは姉妹プロジェクトが挙げる原資料へ進み、実物の該当箇所を確認する。原資料へ到達できない場合は[sourcing.md](sourcing.md)の到達不能手順に従い、Wikipedia側の要約や検索スニペットだけで支持を確定しない。
6. 同じ情報源の転載を複数の独立資料として数えず、特筆性の根拠にも数えない。Wikidata項目、言語版数、記事の長さ、秀逸・良質の選定だけで日本語版における特筆性を立証しない。

## 査読結果の書き方

- Wikipedia記事だけが根拠: `出典不適合（Wikipedia自身の記事）`
- Wiktionaryだけが語義・語源の根拠: `出典不適合（共同編集辞書）`
- Wikidataの値だけが根拠: `出典不適合（Wikidataは本文の出典ではない）`
- 原資料の所在は分かるが未確認: `原資料未確認`
- 転載の証拠を確認した: `循環参照・独立資料として数えられない`
- 兆候だけで確証がない: `循環参照の疑い・要確認`
- 姉妹プロジェクトへの適切な案内: 問題として挙げず、リンク先誤り等がある場合だけリンク監査として報告する

重要な主張が不適合な出典だけに依存する場合は、実質的に適切な出典がないものとして扱う。ただし、主張が虚偽だとは断定しない。存命人物に関する否定的・有害な主張など緊急性の高い場合を除き、通常は信頼できる原資料または独立した二次資料への差し替えを提案する。重大度は、主張の重要性、影響、代替出典の有無、存命人物への危険性に応じて決め、媒体名だけで固定しない。
