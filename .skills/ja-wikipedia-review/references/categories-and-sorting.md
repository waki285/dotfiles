# カテゴリとソートの査読基準

このファイルは、記事全体、カテゴリ、`DEFAULTSORT`、ソートキー、記事末尾のマークアップを査読するときに使う。カテゴリは単なるタグではなく、包含関係を持つ分類・件名体系である。表示されたカテゴリ名だけでなく、記事が実際に所属するカテゴリと、その付与元を確認する。

## 根拠文書と優先順位

1. `Wikipedia:カテゴリの方針`は方針であり、カテゴリ付与、階層、ソートキーの中心的根拠とする。
2. `Wikipedia:過剰なカテゴライズ`はガイドラインであり、定義的でない特徴や過細分を判定する。
3. `Wikipedia:存命人物の伝記`は方針であり、存命人物の機微なカテゴリでは厳格に適用する。
4. `Help:カテゴリ`と`Help:マジックワード`は技術仕様の確認に使う。
5. 分野別ウィキプロジェクトの合意は、状態、適用範囲、下位プロジェクトとの優先関係を確認して使う。

査読時にはライブ版を確認する。特にカテゴリ方針は2026年8月28日に改訂され、過剰なカテゴライズには進行中の告知がある。

## 監査対象を確定する

次を別々に取得する。

- ウィキテキストに直接記述された `[[Category:...]]` または `[[カテゴリ:...]]`。
- インフォボックス、ナビゲーション、スタブ、メンテナンステンプレートなどから間接的に付与されたカテゴリ。
- 通常のカテゴリボックスに表示されない隠しカテゴリと追跡カテゴリ。
- `{{DEFAULTSORT:...}}`、`{{デフォルトソート:...}}`、カテゴリタグごとの個別ソートキー。
- プレビューまたはAPIで得られる実効的な所属カテゴリ。

直接記述がないことを理由にカテゴリ不足と判断しない。逆に、表示上問題がなくても、テンプレートの誤用によって意図しないカテゴリへ入っていないかを確認する。

## カテゴリ付与の基本判定

各カテゴリについて次を確認する。

### 検証可能性

- 記事とカテゴリの関係が、議論の余地のない事実、または本文と信頼できる情報源で裏づけられているか。
- カテゴリだけが主張しており、本文に対応する記述がない状態を見逃さない。
- カテゴリ名は出典や免責表示を伴わないため、論争的な分類は本文以上に慎重に扱う。
- インフォボックスの値を根拠とみなす前に、その値が本文と出典で立証されているか確認する。

### 中立性

- 主観的、評価的、侮蔑的、否定的な含意を持つカテゴリを、編集者の判断だけで付与していないか。
- 「有名な」「重要な」「問題のある」「過激な」など、包含基準が主観的なカテゴリを避ける。
- 論争的な属性は、注釈や帰属を付けられる本文または一覧記事の方が適切か検討する。

### 定義的な特徴

- 国籍・主要職業・地理的位置など、信頼できる二次資料が主題を説明するとき一般的かつ一貫して扱う特徴か。
- 導入部で触れるほど主題の理解に重要な特徴か。実際に導入部に書かれているかだけでなく、書くのが適切かで判断する。
- 一度の出演、短期の居住、些末な受賞、嗜好、外見、単発の関係など、本文から容易に省略できる特徴をカテゴリ化していないか。
- 検証可能であること、記事内で特筆されること、カテゴリとして定義的であることを混同しない。

### 最低限と不足

- 記事は少なくとも一つの適切なカテゴリに所属させる。
- 存在する記事に赤リンクのカテゴリが付いている場合、誤記、改名前の旧カテゴリ、未合意の新設、作成待ちのどれかを確認する。
- 他言語版にあるという理由だけで、日本語版に新しいカテゴリを作成・翻訳しない。

## 階層と重複

- 原則として、カテゴリツリー上で主題に適合する最も具体的なカテゴリへ入れる。
- 記事を子カテゴリとその親カテゴリの両方へ重複して入れない。
- 親カテゴリへも残す `Non-diffusing subcategory`、冠カテゴリ、分野別合意などの例外を確認してから重複と判定する。
- 子カテゴリの全項目が親カテゴリの定義も満たすかを確認する。クラスカテゴリの下へ、包含関係のないテーマカテゴリを置かない。
- 単なる関連性を親子関係としない。包含関係がなく関連するだけなら、カテゴリページ本文で関連カテゴリとして案内する方が適切な場合がある。
- カテゴリ系列が循環していないか、同義またはほぼ同じ包含基準のカテゴリが重複していないかを確認する。

カテゴリページにスコープノートがある場合、カテゴリ名からの推測より、その明示された包含・除外基準を優先する。

## 過剰なカテゴライズ

次の類型を探す。

- 主題を定義しない、枝葉末節の特徴。
- 「人気」「著名」「高級」「凶悪」など主観的な基準。
- 任意の人数、距離、年齢、順位など恣意的な閾値。
- 項目数が乏しく、ナビゲーション上の利益が小さい過度に狭いクロスカテゴリ。
- 「その他」「雑多な」「〜以外」の残余カテゴリ。
- 他カテゴリと大部分が重複するカテゴリ。
- 名称が同じだけで主題上関係しない項目の寄せ集め。
- 「〜に関連する人物」のように関連性の程度が不明なカテゴリ。
- 個人の思想、見解、嗜好、疑惑だけによる人物分類。
- 将来の候補者、受賞候補、就任候補など未確定の状態。
- 出演作品、演じた役、共演者、イベント会場など、主題を通常定義しない関係による分類。

カテゴリに向かない情報でも、本文、出典付き一覧、並べ替え可能な表には適する場合がある。カテゴリ削除だけでなく代替表現を提案する。

## 年代、地域、受賞

- 生年・没年のカテゴリは人物記事で利用できるが、誕生日・命日や死亡場所などによる細分化を避ける。
- 時代別の職業カテゴリは、その時代に実際に活動したことが人物を定義する場合だけ付与する。単に生存期間が重なるだけでは足りない。
- 出生地、居住地、親族の居住地などが本人を定義しない場合、職業との過細な地域クロスを避ける。
- 受賞者カテゴリは、その賞が受賞者の大多数と当該人物にとって定義的な特徴かを確認する。受賞一覧が適切な場合もある。
- 年別・地域別カテゴリを機械的に禁止しない。カテゴリ体系上の分散方法と分野別合意を確認する。

## 存命人物のカテゴリ

- 存命人物の記事には `Category:存命人物` が必要である。
- カテゴリを付けた理由は本文で明らかにし、必要な事実には脚注形式の信頼できる出典を示す。
- `Category:犯罪者`とその下位カテゴリは、現行の存命人物方針が定める条件をすべて満たすかを確認する。犯罪が記事で著名な事項として扱われ、脚注で出典が示され、懲役1年以上の判決が確定していることを要求している。
- 宗教カテゴリは、信頼できる媒体の脚注が必要である。日本人または日本在住の存命人物では、本人が信仰を広く公表する意思も確認する。
- 性的指向のカテゴリは、本人による公表と、その属性が著名な活動または公的人生に重要な関連を持つことの両方を確認する。
- 人物への評価が低いと示唆するカテゴリ、疑惑、容疑、政治的・宗教的レッテルは、安全側に倒して扱う。

### 生年関連

- 生年が確認できる存命人物には、適切な生年カテゴリを付ける。
- `生年不明`、`生年非公表`、`生年未記載`は意味が異なる。本人・所属組織が明示的に非公表としている場合と、単に信頼できる資料を確認できない場合を区別する。
- 故人となった人物から `存命人物`、`生年非公表`、`生年未記載`など存命人物専用カテゴリを外し、没年カテゴリを検討する。

## 人物記事の分野別カテゴリ

`プロジェクト:人物伝`と、その下位プロジェクトの現行合意を確認する。

- 百科事典に掲載される理由となった主要な職業・活動分野のカテゴリを付ける。
- 人物を定義する地域カテゴリを付け、職業と地域を組み合わせた適切な具体的カテゴリがあればそれを利用する。
- 判明している生年、故人なら没年のカテゴリを付ける。
- 付加的カテゴリは、一覧記事の方が適切でないか、過剰なクロス分類にならないかを確認する。
- 下位プロジェクトに職業・競技・芸能分野の合意がある場合、その適用範囲では下位合意を優先する。

人物自身の冠カテゴリは、直接関連する記事・サブカテゴリが十分にある場合だけ検討する。固定的な項目数だけで新設を判断せず、現行のカテゴリ方針とプロジェクト合意を確認する。

## `DEFAULTSORT`の基本

日本語の文字を含むページ名では、カテゴリ内を意味のある五十音順にするため、通常 `DEFAULTSORT`を設定する。

```wikitext
{{DEFAULTSORT:そおときい}}
[[Category:カテゴリ名]]
```

- 一般に読みをひらがなで記す。
- 濁音・半濁音を清音へ、拗音・促音を直音へ、長音を対応する母音へ置き換える。
- 曖昧さ回避の括弧書きは通常、ソートキーへ含めない。
- 中黒、疑問符、感嘆符、括弧、ハイフンなど、読みに関係しない約物は通常無視する。
- 平仮名の清音だけで構成される項目名には通常不要だが、姓名を区切る人物名などは設定する。
- 複数の読みがある項目名は、代表的な読みを一つ選ぶ。

長音の母音への置換や固有名詞の読みを推測しない。記事本文と信頼できる情報源で読みを確認する。

### 人名

- 姓名形式は、姓、半角空白、名の順で記す。外国人名も、姓を特定できる場合は姓を先にする。
- 名跡、筆名、芸名など、姓と名のように慣用される名称も同様に扱う。
- 姓と名から構成されない単名は、名称の読みをそのまま記す。
- 複合姓、複合名、ミドルネーム、姓の前置語は、当該言語と人物の慣用を確認する。見た目だけで分割・並べ替えしない。
- 歴史上の日本人名で姓と名の間を「の」と読む場合は、その読みと区切りを反映する。

### 欧文、数字、混成名

- 欧文だけの項目名には原則として `DEFAULTSORT`は不要である。
- 欧文と和文の混成名は、欧文部分を原表記、和文部分を読み仮名とするのが基本である。
- カナによる慣用読みが定着した欧文名は、例外的に読みをソートキーとする場合がある。カテゴリ内の整列も確認する。
- 数字を読み仮名にするか数字のままにするかは、カテゴリが五十音順と番号順のどちらを意図するかで決める。
- 番号順では必要に応じて先頭を `0`で埋め、桁数を揃える。カテゴリ独自の方式は説明または合意を確認する。

## `DEFAULTSORT`と個別ソートキーの技術監査

- `DEFAULTSORT`は最初のカテゴリタグの一行上に置く。
- 個別の `[[Category:名称|ソートキー]]`は、そのカテゴリについて `DEFAULTSORT`を上書きする。
- `DEFAULTSORT`が複数存在すると、ソース上で最後に有効となるものが適用される。テンプレート経由の隠れた定義を含めて重複を確認する。
- 個別キーの相違が意図的か、古い表記の残骸かを確認する。全カテゴリに同じ個別キーを繰り返すより、共通なら `DEFAULTSORT`を使う。
- カテゴリの中心記事は、個別ソートキーに半角空白を指定して先頭へ置く慣例がある。
- 重要な関連ページに `*`、メタカテゴリに `+`などの特殊キーを使う場合、カテゴリの運用説明と既存項目の慣例を確認する。

`DEFAULTSORT`は記事の読み仮名を表示する機能ではない。導入部の読みと目的を混同しない。

## 記事末尾での配置と表示順

- カテゴリタグはウィキテキスト末尾へ置き、`DEFAULTSORT`は最初のカテゴリタグの直前に置く。
- カテゴリボックスは、処理後のウィキテキストに現れるカテゴリ宣言の順に表示される。
- 明確な絶対順はないが、冠カテゴリを先頭にし、おおむね具体的から抽象的、定義的から付加的へ並べる。
- 人物記事では生年・没年カテゴリを最後に置く。
- 末尾テンプレート、典拠管理、スタブ、ナビゲーション、カテゴリの標準順は、レイアウトの現行版と分野別合意を確認する。順序だけの差で意味が変わらなければ原則 `軽微`とする。

## 冠カテゴリ

- 人名、地名、団体名など記事と同一主題のカテゴリは、直接関連する記事やサブカテゴリが十分に存在する場合だけ作成する。
- 主記事は冠カテゴリに含め、通常、個別ソートキーの半角空白で先頭に配置する。
- 冠カテゴリがあることだけを理由に、主記事から広い分類カテゴリをすべて除かない。カテゴリツリーと既存合意に沿って、冠カテゴリと主記事のどちらを親カテゴリへ残す方式か確認する。
- 個々の作品を作家の冠カテゴリへ直接大量投入せず、適切な作品サブカテゴリがあるかを確認する。

## テンプレートと隠しカテゴリ

- テンプレート自体のカテゴリは解説サブページまたは `noinclude`内、呼び出し元へ付与するカテゴリは通常 `includeonly`内に置く。意図しない名前空間を巻き込んでいないか確認する。
- テンプレート経由の通常カテゴリ、メンテナンスカテゴリ、追跡カテゴリを区別する。
- 記事管理用の追跡カテゴリは原則として隠しカテゴリにする。スタブカテゴリはこの一般則の例外である。
- 隠しカテゴリは通常表示されなくても、プレビュー、ページ情報、API、ソースで確認できる。
- テンプレート変更後はジョブキューとキャッシュのため、カテゴリ反映に時間差が生じることがある。表示差だけでウィキテキストの誤りと断定しない。

## カテゴリの改名、赤リンク、リダイレクト

- 日本語版ではカテゴリ間のリダイレクトを作成しない。移動後も各所属ページのカテゴリタグは自動移行しない。
- 旧カテゴリへの所属、似た名称の重複カテゴリ、誤字による赤カテゴリを確認する。
- 広範な改名、統合、削除が必要なら、記事一件だけを直して終わらせず、現行の提案・議論手順を案内する。
- 査読依頼だけでは、新カテゴリ作成、カテゴリの大量置換、改名提案、削除依頼を実行しない。

## カテゴリ、一覧、ナビゲーションの役割分担

- カテゴリは説明なしの集合と階層ナビゲーションに向く。
- 一覧記事は包含理由、注釈、出典、日付、比較項目を示す必要がある場合に向く。
- ナビゲーションテンプレートは、明確に定義された関連項目を記事間で案内する用途に向く。
- カテゴリ内の項目ごとに説明や出典が必要なら、カテゴリだけで済ませず一覧または本文を検討する。

## ソース監査の検索観点

全文査読では次を検索し、表示結果と照合する。

- `{{DEFAULTSORT:` と `{{デフォルトソート:`: 欠落、複数定義、読み、配置。
- `[[Category:` と `[[カテゴリ:`: 直接カテゴリ、赤リンク、個別ソートキー、親子重複。
- `| `、`|*`、`|+`、数字キー: 特殊な整列がカテゴリの慣例に合うか。
- インフォボックス、ナビゲーション、スタブ、メンテナンステンプレート: 間接カテゴリの付与元。
- `存命人物`、生年、没年、生年不明・非公表・未記載: 人物の状態と一致するか。
- 犯罪、宗教、性的指向、政治的立場など: 本文、脚注、本人の公表、方針上の条件。

検索ヒットだけで判定せず、カテゴリページの説明文、親子構造、テンプレート展開、関連ウィキプロジェクトの合意を確認する。

## 報告方法

全文査読では、次を簡潔に示す。

| 項目 | 内容 |
| --- | --- |
| 実効カテゴリ | 通常、隠し、追跡カテゴリを区別した一覧 |
| 付与元 | 直接記述 / テンプレート名 / 不明 |
| 根拠 | 本文と出典で立証される定義的特徴か |
| 階層 | 最も具体的か、親子重複や誤った包含がないか |
| ソート | `DEFAULTSORT`、個別キー、実際の並び |
| 判定 | 適切 / 修正推奨 / 要確認 / 対象外 |

存命人物への有害または機微な無出典カテゴリは、内容方針上の問題として `緊急`または`重大`を検討する。カテゴリの根拠不足・誤分類は通常 `中`、`DEFAULTSORT`の読みや配置、表示順だけの問題は通常 `軽微`とする。ただし、同名項目の発見性を大きく損なう場合は影響に応じて引き上げる。

根拠ページと調査固定版は [sources.md](sources.md) を参照する。
